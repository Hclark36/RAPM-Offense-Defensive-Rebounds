# RAPM-Offense-Defensive-Rebounds

A reusable model estimating players' adjusted contributions to team offensive and defensive rebounding.

[Explore the interactive dashboard](https://hclark36.github.io/RAPM-Offense-Defensive-Rebounds/)

Search players, compare ratings, explore rankings, and review the model methodology. Results cover the 2023–24 through 2025–26 regular seasons.

[View Mitchell Robinson](https://hclark36.github.io/RAPM-Offense-Defensive-Rebounds/#player=1629011)

The standalone dashboard is published from `docs/index.html` on the `main` branch using GitHub Pages.
